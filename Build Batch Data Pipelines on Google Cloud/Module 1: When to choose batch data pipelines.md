# Module 1: When to choose batch data pipelines

- Automated system or infrastructure that implements batch data processing (collecting data over a period, then processing in a single run).
- Triggered by a schedule on a periodic basis, or by a predefined event.
- When the data you are operating on is complete and historical rather than real-time.
- When it is a task that does not require real-time ingestion.
- When the cost of streaming is too high and not required for the use case.
