# Google Data Engineer

Study repo for the [Preparing for Google Cloud Certification: Cloud Data Engineer Professional Certificate](https://www.coursera.org/professional-certificates/gcp-data-engineering) Coursera course.

## Contents

- **Notes** — write-ups and summaries from course material
- **Snippets** — code samples from course exercises
- **Projects** — personal projects built to get hands-on with key GCP data products (BigQuery, Dataflow, Pub/Sub, Cloud Composer, etc.)
